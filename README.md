# Eventify - Frontend

Веб-інтерфейс для платформи **Eventify**, призначений для перегляду подій, артистів, майданчиків та інформації про проєкт. Фронтенд працює як окремий клієнт і взаємодіє з Django REST API через асинхронні `fetch`-запити.

---

## 🌐 Використовувані порти та адреси
- **Фронтенд (клієнт):** запущено на `http://127.0.0.1:5500` (або `http://localhost:5500`)
- **Бекенд (API):** працює на `http://127.0.0.1:8000/`

---

## 🚀 Як запустити проєкт

1. Переконайтеся, що у вас запущений бекенд-сервер (Django) на порті `8000`.
2. Клонуйте або відкрийте цей репозиторій у вашому терміналі/редакторі коду.
3. Запустіть проєкт одним із зручних способів:
   - **Через Node.js (Live Server):** у кореневій папці фронтенду виконайте команду в терміналі:
     ```bash
     npx live-server --port=5500
     ```
   - **Через розширення у VS Code:** відкрийте файл `index.html`, натисніть правою кнопкою миші та виберіть **"Open with Live Server"**.
4. Проєкт автоматично відкриється у браузері за адресою `http://127.0.0.1:5500` і почне успішно завантажувати дані з бекенду (налагоджено підтримку CORS).
